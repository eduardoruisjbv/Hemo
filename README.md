# Hemo

Addon para World of Warcraft Retail que exibe efeitos de sangue nas bordas da tela quando a vida está baixa e efeitos vermelhos para acertos críticos.

## Instalação

Copie a pasta `Hemo` para `World of Warcraft/_retail_/Interface/AddOns/`.

## Desenvolvimento

Os arquivos Lua e as texturas são empacotados pelo CurseForge como `Hemo`. Os scripts de geração de texturas em `tools/` ficam no repositório e não entram no pacote do addon.
